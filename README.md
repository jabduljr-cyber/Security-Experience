# Security-Experience


I went through the Michigan State University Cybersecurity Bootcamp from June to December 2024. We covered pretty much every topic you'd need for Security+, including cryptography and penetration testing. Then life got busy and I went back to full-time work, so I didn't keep up the hands-on side the way I wanted to.

I'm picking that back up now. This folder is where I'm putting what I learned in the bootcamp and what I'm relearning as I go.

## What the bootcamp covered

- General security concepts and the basics of how security controls work
- Threats, vulnerabilities, and how to defend against them
- Security architecture and network defense
- Security operations and incident response
- Cryptography: encryption, hashing, and how certificates work
- Penetration testing and ethical hacking
- Governance, risk, and compliance

## Where I am now

- Studying for CompTIA Security+ (SY0-701) every day. Exam is planned for November 2026.
- Going back through my old bootcamp work and redoing labs so I actually understand it again, not just remember that I did it.
- Writing up what I find in this repo as I go.

## What I'm aiming for

I want to work as a SOC analyst or in IT support while I keep building toward more certs. I've worked overnight and in security and customer-facing roles, so watching for problems, writing things up clearly, and knowing when to escalate is already how I work. I'm adding the technical side on top of that.
