# Security-Experience

I went through the Michigan State University Cybersecurity Bootcamp from June to December 2024. We covered pretty much every topic you'd need for Security+, including cryptography and penetration testing. After it ended I went back to full-time work and didn't keep up the hands-on side the way I wanted to.

I'm picking that back up now. This folder is where I'm putting what I learned in the bootcamp and what I'm relearning as I go.

## My favorite parts

**Packet analysis.** This was my favorite thing we did. Seeing what's actually moving across a network, and learning to pick out what's normal and what isn't, is what made security click for me. It's also the part I most want to do for a living.

**S3 buckets.** I enjoyed learning how S3 buckets work and how they're set up and locked down. It showed me how a simple misconfiguration can expose a lot of data, and why access settings matter so much in the cloud.

## What the bootcamp covered

- Security concepts and how security controls work
- Threats, vulnerabilities, and defenses
- Network security and architecture
- Security operations and incident response
- Cryptography
- Penetration testing and ethical hacking
- Cloud basics, including S3
- Risk, governance, and compliance

## Where I am now

- Studying for CompTIA Security+ (SY0-701) every day. Exam is planned for November 2026.
- Redoing old bootcamp labs, starting with packet analysis, so I actually understand them again and not just remember doing them.
- Writing up what I find here as I go.

## What I'm aiming for

I want to work as a SOC analyst or in IT support while I keep working toward more certs. I've worked overnight shifts and in security and customer-facing jobs, so watching for problems, writing things up clearly, and knowing when to escalate is already how I work. I'm building the technical side on top of that.
